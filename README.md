# CareerFit

취업 컨설팅 화상면접 플랫폼.
WebRTC 기반 1:1 화상면접, 결제 시스템, 등급별 구독 모델을 제공한다.

## 기술 스택

- React 19, TypeScript, Vite
- Tailwind CSS, React Router v7, Axios
- OpenVidu (WebRTC), PortOne
- JWT 인증

## 팀 구성

- Frontend: 1명 (본인)
- Backend: 4명

프론트엔드 전담

## 주요 기능

- OpenVidu WebRTC 기반 1:1 화상면접 및 실시간 채팅
- PortOne 결제 SDK 연동 및 등급별 가격 책정
- JWT 기반 인증 및 토큰 자동 갱신
- React Router v7 기반 SPA 아키텍처 (30개+ 페이지)
## 개발 기간

2025.08.11 ~ 2025.09.30
